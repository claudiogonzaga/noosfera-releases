# Noosfera · versões publicadas

Este repositório guarda só os **instaladores** da Noosfera — o APK do celular (Android) e o DMG do Mac — e as notas de cada versão. Não há código-fonte nem dados aqui.

- Página para baixar: **https://consciencia.eco.br/noosfera**
- Links fixos (sempre a versão mais nova): `consciencia.eco.br/noosfera/android` e `consciencia.eco.br/noosfera/mac`
- Os apps procuram atualização em `consciencia.eco.br/noosfera/versao` e conferem o SHA-256 do instalador antes de instalar.

Cada versão é uma release com a etiqueta `android-vX.Y.Z` ou `mac-vX.Y.Z`; o corpo da release traz as notas e a linha `SHA-256: …` do instalador.
